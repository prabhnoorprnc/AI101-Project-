### CPU Performance Prediction Using Multiple Linear Regression

#### Project Overview

This project aims to predict the relative performance of CPUs using their hardware specifications through Multiple Linear Regression.

The model uses hardware-related features such as:

- Cycle Time
- Minimum Main Memory
- Maximum Main Memory
- Cache Size
- Minimum Number of Channels
- Maximum Number of Channels

The target variable is Estimated Performance .

The project involves data preprocessing, exploratory data analysis, model development, and performance evaluation to understand how hardware specifications influence CPU performance.

#### Project Objective

To build a Multiple Linear Regression model that estimates CPU performance based on hardware specifications and evaluates its predictive accuracy using given and appropriate regression metrics.
